# CP-F2: the box's identity inside the one Palee app

Status: options for a product-owner decision (no code yet).
Mockup: `v31-mockups/w7-trust.html`, section F2 (screen 12).

## The fixed rule

`docs/brand/THEME.md`: one Palee theme for everyone. No box chooses a theme,
and a box's brand colours never tint the app, the kiosk or the public pages.
A box shows itself through its **logo, name and photos**. Palee is a network:
one member can belong to several boxes, so the app is never "the box's app".

Not allowed by any option below:

- per-box colour themes, accent colours, fonts or icons inside the app;
- a separate store app per box (white label);
- the box's colour on buttons, tabs, chips or charts.

## What already exists

- Logo, name and public profile of the box (settings `brand_name`,
  `brand_logo_url`); `brand_primary_color` is stored but tints nothing in the app.
- Join links per client role (ADR-216) and the public join link (ADR-106).
- Universal links / app links from the native wrapper (ADR-171) for `/join/`,
  `/b/`, `/c/` and similar paths.
- Wallet passes (`application/wallet_passes.ex`) that carry the box name and logo.

## Options

| | A. The box inside Palee (recommended) | B. The box first | C. Instant experience |
|---|---|---|---|
| What the member sees | Box tab opens with cover photo, logo and name; the rest in Palee colours | As A, and a member of one box lands on the Box tab, not the Feed; "Add Box Kypseli to the home screen" shortcut | Scan the QR at the box, a small part of Palee opens without install (App Clip / Android Instant App): check-in, booking, pay |
| Join link and QR | Opens the app straight at the box (universal link), or the web join page | Same | The QR launches the clip |
| Work | Small: Box tab header, poster QR, deep-link routing | A + start-tab rule + shortcut/PWA manifest per box path | Native targets, store review, size limits |
| Risk | Low | The shortcut with the box's name looks like a branded app and blurs Palee | Big effort before pilots; small gain until door access (CP-E3) |

## Recommendation

A now. From B, only "open on the Box tab for members of exactly one box".
C later, together with door access (CP-E3), if pilots ask for walk-in check-in.
